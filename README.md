# Atlist

**Date:** September 11, 2026

## Overview

Atlist is an interactive, digital daily-checklist system for people living with memory disorders, including dementia and Alzheimer’s disease.

The project consists of physical tabletop or wall-mounted devices, each about the size of a small clock radio. Each device presents a small set of large, tactile, single-purpose controls—such as physical buttons, toggle switches, or dials—for the day’s core homeostasis activities:

- Brushing teeth
- Bringing keys and wallet
- Taking medication
- Drinking water
- Movement
- Sleep

The system is designed to be as intuitive as a light switch. It has:

- No login
- No menus
- No typing
- No microphones, speakers, or cameras, avoiding concerns about surveillance

## Project Goals

- Build a working prototype with physical inputs and feedback.
- Support a customizable reset cycle, such as every 24, 12, or 6 hours.
- Create a simple app that sends to-do items to the prototype.
- Conduct tests with real users.
